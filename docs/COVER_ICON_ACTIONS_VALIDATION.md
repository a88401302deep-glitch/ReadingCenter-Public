# 封面像素獨立列／四圖示工具列

2026-10-30。唯一目標：像素資訊獨立一行，搜尋、上傳、貼上、移除固定一排四個圖示；滑鼠停留或鍵盤 Tab 聚焦顯示短功能名稱。

## 修改

- `BookForm.tsx`：像素移出工具列，四個操作固定位置；沒有封面時移除停用。原生檔案選擇器移至工具列外，保留上傳驗證與既有封面儲存方式。
- `CoverIconButton.tsx`、`Icon.tsx`：柔和粉色圓角按鈕、統一線條圖示與 CSS 提示，保留完整無障礙按鈕名稱。
- `BookCoverPaste.tsx`：新增圖示模式，原有剪貼簿讀取、直接貼上與權限拒絕後的備援輸入區維持。
- `site-theme.css`：四等分、最小 44px 觸控範圍；錯誤與備援輸入占下一整列。
- `tablet-editor.spec.ts`：320／360／430px 手機及 768／1024／1366px 平板驗證同排、像素列位置、觸控尺寸、滑鼠提示、實際 Tab 聚焦提示及離開後隱藏。

## 驗證

- 元件 3 檔 14 項通過：封面編輯、貼上、編輯範圍。
- 最終版面 E2E 8 項 Chromium／WebKit 全過且無重試；另先前同批封面候選 2 項通過。
- TypeScript／build、範圍 ESLint、diff check 通過；原有打包大小提示保留。未跑完整 CI。
- 首輪把隱藏原生檔案按鈕計入工具列，已將其移至列外。第二輪 Chromium 因滑鼠後程式 focus 不代表鍵盤 focus-visible，改以真實 Tab／Shift+Tab 驗證後通過；未放寬提示可見性要求。

## 交付與驗收

合成預覽在根工作區 `.local-dev/cover-icons-design/`：`tablet-editor-1024.png`、`phone-editor-360.png`，已目視。

1. 開啟平板或手機預覽圖，確認像素與四圖示分兩行。
2. 本機編輯書籍中，滑鼠停在圖示或使用 Tab 聚焦，檢查搜尋／上傳／貼上／移除提示。
3. 點選圖示依原方式操作；沒有圖片時移除停用。
