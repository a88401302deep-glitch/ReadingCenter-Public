# 獨立封面／緊湊書籍資料，本機預覽

2026-10-30。唯一目標：封面獨立，但不佔平板整排；整合書籍與出版資料，避免欄位被封面高度拉開。

## 完成內容

- 760px 起，左側為 200px 封面與備註，右側為雙欄書籍資料。兩側獨立向上排列；封面下方的備註不受長作者高度影響。
- 書名、作者、出版社、ISBN、日期、原文書名、人名、系列、卷次及字數統一在書籍資料區。「補資料」與標題同行，查詢時才展開工具。
- 短書名、人名維持單行高度，長內容自動增高；超過 64 字或 3 個換行的人名／書名使用資料區整列。
- 手機維持封面滿內容寬度、不裁切，依序顯示封面、資料、備註。橫直向切換保留輸入與封面候選。
- 不變更儲存結構、既有書籍、封面檔案或正式資料；封面路徑仍不顯示為輸入欄。

## 驗證

- 5 個元件測試檔，共 29 項：編輯範圍、封面編輯／貼上、出版社選用及書目搜尋。
- 最終 Chromium／WebKit 共 22 項 E2E：tablet-editor、adaptive-editor、cover-picker、metadata-flow；最後執行結果 passed、無失敗。
- 涵蓋 768／1024／1366px、手機 320／360／430px、30 位作者保存重開、橫直向切換、備註位置、候選封面保存及搜尋帶入。
- TypeScript／建置、範圍 ESLint、git diff --check 通過。未執行完整 CI、未承接私人候選。
- 初輪標籤與舊區塊定位失敗已診斷，補上明確欄位名稱並更新區塊定位後通過；非以重試掩蓋失敗。一次測試路徑輸入錯誤沒有執行測試，修正至 tests/component 後完成。
