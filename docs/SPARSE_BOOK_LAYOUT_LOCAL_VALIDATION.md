# 少量書目與iPad版面本機驗證

2026-10-29，基準公開maind685a73，本次唯一目標：改善使用者iPad照片中少量書目造成的標題／欄位高度拉伸與不平衡。沒有使用私人圖片作測試資產。

- 書目區與每列自然收高、靠上對齊，不隨封面高度撐滿；空欄位仍隱藏，不再顯示大片白色空格。
- 瀏覽時已填欄位不超過3個（含書籍版本），平板／桌面1024px起改為左封面、右書名作者及已填資料。手機仍封面置中、書名在下方。較完整書目與管理模式保留原排列。
- 少量書目顯示淡色提示「僅顯示已填資料。可由上方『編輯書籍資料』補充書目資訊。」不把資料少判為錯誤或從未編輯，不臆造資料或要求填滿非必要欄位；編輯仍開完整表單。
- 空心得區內距收斂；原粉色標題帶、主頁同寬、浮動X與既有編輯入口保留。

驗證：10項元件／App閱讀整合通過，包含少量提示／較完整不提示、資料不變；最終36項Chromium／WebKit通過，包括觸控360／1024／1366少量長書名、欄高、右側書名、編輯返回、320至1440及200%文字、短筆電／觸控條件。自然收高初版36項通過後，進一步集中右側圖文，對新排列更新明確斷言，最終36項再次通過。typecheck／範圍lint／build／diff check通過；未執行完整CI。

合成預覽.local-dev/sparse-book-design/ipad.png、mobile.png已目視核對。僅本機，尚無私人承接／PR／部署，正式站仍c15048d。
