# 單書分區、編輯樣式與實心圖示：本機驗證

唯一目標：依使用者進一步回饋，修正上一版本右上管理字樣與空白列、封面旁只有書名作者造成的空白，統一編輯視覺，並更換導覽及頁面圖示。使用者明確選擇「簡潔實心圖案，少量柔和配色」；手機導覽只顯示圖示。承接尚未發布的aeed624，本輪仍未部署。

## 完成行為

- 移除獨立book-detail-tools整排入口。編輯書籍資料位於書籍資料卡標題旁，仍一次直接開完整編輯與內嵌書目查詢。原分項與封面工具保留，關閉編輯工具後回到閱讀狀態。
- 書籍資料用淺色卡片，桌面封面240px與真實書目欄位並排，書名／作者移到封面下；分類、來源、標籤與評分在同卡下方。書目欄位採類似新增表單的標籤／值與淡底分組，沒有假裝為可直接輸入的input。
- 閱讀紀錄用米色、心得用淡玫瑰色。1280px以上書籍卡在左、兩個閱讀區塊在右，頂端對齊；1024px中間尺寸閱讀／心得在書籍卡下方並排；手機維持大封面與單欄順序。沒有內容摺疊。
- 入口明確命名為編輯書籍資料／編輯閱讀紀錄／編輯心得；啟用後以完成…編輯結束，閱讀與心得草稿保護保留。
- 共享Button新增edit語意變體：鉛筆圖示、同一圓角外框與配色、44px高度。書籍分項、閱讀分次、每日紀錄、心得及月份配色編輯已採用；閱讀筆記原IconButton編輯入口以同一規則呈現。儲存、取消及刪除保留各自用途。
- 共享Icon／EntryIcon改簡潔實心書本、書架、紙頁、鉛筆、設定與格狀圖案；換掉舊圓形徽章與首頁心得字元圖案。保留玫瑰、鼠尾草綠、奶茶點綴，修正舊導覽選取樣式使實心圖示變淡的問題。
- 手機導覽文字以CSS隱藏；button保留明確aria-label、title與aria-current，圖示aria-hidden，不新增可聚焦裝飾。桌面保留圖示與文字，手機點擊範圍維持44px以上。
