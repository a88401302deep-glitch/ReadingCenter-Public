# 封面優先的書籍編輯排版

2026-10-30，基準公開 main 8730eac／私人 main 56869ce。本批唯一目標：修正 iPad 編輯表單的資訊優先順序及不平衡留白。

- 書名／作者與封面放在表單最前，書目查詢移至其後。760px 以上封面在左、姓名欄位與封面操作在右；1000px 以上書名與作者並排、封面 200×280；較窄平板封面 180×250；手機書名／作者在上，封面置中。
- 未設定封面有清楚佔位；選檔／貼上／搜尋與移除操作靠近封面，按鈕不再橫向拉滿。原始封面路徑進階欄仍保留在表單後方，不影響正常選圖。
- 完整編輯中，分類與標籤置同一區，平板雙欄、手機單欄，說明跟隨各自選單；舊 bibliography／personal scope 維持原有可編輯欄位。所有既有 metadata、封面草稿、儲存／取消／版本衝突流程不變。
- 沿用粉色、字體、圓角與固定底部儲存／取消，不改資料結構、API、migration、設定或正式資料。

驗證：23 項元件測試通過（封面失敗／取消／草稿、分區寫入保護、書目補全）；16 項 Chromium／WebKit 瀏覽器通過（768 直向、1024×768 橫向、1366 平板、360 手機，實際合成封面與空封面、首屏位置、選圖採用與取消、分類儲存／篩選、來源圖示）；typecheck、範圍 lint、build、diff check 通過。首輪發現寬版書名過長已調整；測試準備合成封面時需展開舊新增表單的路徑欄，已修正測試操作。未以重試替代修正。

合成截圖：本機 .local-dev/cover-first-design/tablet-editor-1024.png、phone-editor-360.png 已目視。沒有使用正式書籍、封面或私人備份。

驗收：開啟任一本書→編輯書籍資料，進入即見封面／書名；更換封面後先核對預覽，再儲存回單書頁；往下核對分類與標籤平板並排且無橫向溢出。完整 CI 與私人逐檔等效另行記錄，正式發布須依 CONTRIBUTING.md 另外授權。
