# 統一書籍編輯與iPad表單：本機驗證

2026-10-29，基準公開main05e1ce3。使用者提供iPad照片並明確選擇「單一完整表單」；本批唯一目標是統一瀏覽／編輯介面，修正層級與表單尺寸。

## 行為
- 導覽統計改淡粉圓角膠囊，書本圖示搭配讀完／藏書分列數字，沿用同一份ReadingOverview與原可讀標籤，未改計數資料。
- 移除單書區READING JOURNAL裝飾；無封面圖的裝飾改中文。書名原有英文保留。
- 點編輯書籍資料直接開完整表單，儲存成功直接回單書頁，取消也回瀏覽；移除中間管理模式、完成書籍編輯及分別編輯分類／評分等次級入口。分類、來源、評分、出版資訊與封面均可在同一表單處理。刪除移到單書底部更多書籍操作，保留原確認與資料清除流程。
- 完整編輯時原文書名／譯者／繪者及封面路徑直接展開；760px起雙欄，較小手機單欄。欄位依內容自然收高；表單擴到最大1100px，只有欄位區捲動，取消／儲存固定可見。查詢區縮緊，查詢方式及來源的進階選項仍可展開；這些是查詢操作，並非被隱藏的書籍欄位。
- 草稿取消確認、儲存中重複提交阻擋、版本衝突、封面先預覽後儲存均保留。修正儲存後焦點還原：等busy解除並還原原頁可見狀態，再回到編輯入口與原捲動位置。

## 驗證
- 最終9檔34項元件／App整合通過，涵蓋草稿、重複提交、版本衝突、保留欄位、分類與出版資訊同表單、評分、語言、封面及Header。
- 76個相關Chromium／WebKit案例分層驗證。首輪64通過、12失敗；診斷為改版後測試定位、fieldset computed style字串假設、測試輔助匯入遺漏，修正後9項通過，另3項暴露實際儲存返回焦點時序問題，程式修正後3項通過。保留實際欄位座標與返回焦點斷言，未跳過案例或降低檢查。
- 最後縮緊查詢區後重跑最相關26項，全部通過，涵蓋768／1024／1366觸控完整表單、360px手機、1280px桌機、固定操作列、欄位尺寸、儲存取消、搜尋核對與封面；其餘已驗證閱讀／刪除／同步／單書返回案例依修改範圍引用，未反覆跑全套。
- typecheck／範圍eslint／build／diff check通過。未跑完整CI，尚未私人承接／推送／PR／部署。沒有正式書籍或封面資料讀寫，使用者照片未作測試資產。
- 合成預覽.local-dev/unified-editor-design/ipad-editor.png及header-stats.png已目視核對。新表單資料多時仍需在同頁捲動，並非把所有欄位塞進一屏；模擬測試不等於實機驗收。

## 本機驗收
1. 對照統計膠囊與iPad完整表單預覽；書名英文保留，獨有英文裝飾消失。
2. 點編輯直接看到所有書籍欄位分區，在同頁補資料，取消／儲存保持可見。
3. 儲存直接回單書頁，沒有中間鉛筆管理層；再開表單確認已存值，取消草稿仍受保護。
