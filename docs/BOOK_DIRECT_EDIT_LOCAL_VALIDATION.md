# 單書實機回饋修正：管理直接編輯與桌面封面

唯一目標：修正使用者指出入口不像按鈕、書籍管理多一層、桌面封面縮小及留白過多。從已合併公開main04df58e建立codex/book-detail-direct-edit，不重做前批功能，不動私人資料或部署設定。

## 完成行為

- 三個管理入口採明確底色、外框、44px高度及選取狀態。修正原透明工具按鈕規則覆蓋閱讀管理底色，保留閱讀／心得管理草稿保護。
- 第一次點管理書籍直接開既有完整BookForm，出版資料、分類、評分、封面均可編輯；書目查詢直接在表單頂部顯示查詢書名及查詢按鈕，不再先進管理再點編輯書籍或另外開查詢視窗。不自動發出查詢或改寫資料。
- 關閉表單後原管理工具仍可使用，按完成書籍管理回到瀏覽；書目／閱讀／心得直接可讀，沒有新增內容摺疊。原分項工具及封面工具保留。
- 1024px以上桌面封面由112px改為最高220px，左欄封面與書目、右欄閱讀／心得；閱讀區從封面旁開始，避免頂部封面橫跨全寬而留下空間。手機維持獨立置中最高320px封面、書名在下。
- 新inlineMetadataSearch只用於這個完整管理表單；新增書籍及原分項表單沿用原查詢方式。沒有更改資料服務、儲存語意、版本保護、閱讀事實或正式資料。

## 驗證

- 相關元件3檔14個不同案例通過：app-library-reading、app-inline-book-edit、book-form-scope。新增原始點擊管理書籍後直接取得查詢／出版書名欄位的檢查，取消不改資料。既有分項測試helper明確關閉新完整表單，再驗證原分項工具；直接入口回歸測試不依賴該helper。
- Chromium／WebKit5檔36個不同案例具備分批通過證據：book-detail、book-quiet-browsing、book-inline-edit、book-reading-groups、reading-record。首輪30通過、6個桌面案例仍要求閱讀與書目頂端對齊而失敗；依新版驗收改為閱讀與封面頂端對齊，補驗16項全通過，包含原6失敗及相關尺寸／一鍵表單。
- 核對320、360、768、1024、1280、1440px、200%文字、返回位置、連續儲存、草稿保護、分次閱讀與手機彈窗。三個管理按鈕皆有實際底色／邊框，桌面封面200–220px，查詢及出版書名欄位直接可用。
- Typecheck、正式build、修改範圍ESLint與diff check通過；既有BookMetadataDialog ref警告1項與sql.js／chunk建置提示保留。未跑完整程式套件、完整瀏覽器套件或CI。
