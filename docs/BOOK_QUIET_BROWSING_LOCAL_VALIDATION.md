# 單書瀏覽按鈕減量與字體參考：本機驗證

本輪唯一目標：修正使用者實機指出「仍有很多編輯按鈕」，並在同一單書頁套用最新圖片的字體方向。前批只淡化按鈕樣式，沒有真正降低入口數，不能視為這項瀏覽體驗已驗收。

## 實作與範圍

- 基底為已發布公開main `bb91f99076c3621deb5b169bd1ec547dac612c99`，本輪已唯讀核對GitHub一致。沿用乾淨公開隔離副本，新分支 `codex/book-detail-quiet-browsing`；沒有在舊搜尋分支開發。
- 預設只有「管理書籍、管理閱讀、管理心得」3個單書管理入口。封面搜尋／更換／上傳、書目／分類／評分、閱讀狀態選單、逐次更新／編輯／刪除、心得新增／編輯／刪除，進入對應管理模式才顯示。關閉管理模式後恢復3個入口，書目／紀錄／心得始終直接可讀，不摺疊內容或依賴hover。
- 缺資料在瀏覽時顯示「未提供」，避免滿頁鉛筆圖示像編輯按鈕；書籍管理模式仍保留原缺漏提示。沒有紀錄的未分次區不再空占瀏覽畫面，管理模式仍可新增。
- 閱讀紀錄彈窗／分次閱讀／心得尚有表單或刪除確認時，禁止關閉對應管理模式。閱讀彈窗因外部點擊關閉後，草稿保留、重新開啟可繼續；記錄編輯狀態以cycleId集合追蹤，不會因另一筆視窗關閉而清掉待編輯狀態。完成閱讀管理的pointerdown不提前關閉彈窗，以免畫面位移吞掉click。
- 字體參考使用者圖片的圓潤無襯線方向與較厚標題；單書頁／彈窗標題及統計數字採系統字體堆疊，重要標題600字重。手機／桌面字級與資訊密度維持前批分工；實際字形依裝置可用字型而異，不宣稱已辨識或使用圖片同款字型，沒有新增大型字型下載。既有封面圖片及替代封面不被改成其他內容。
- 限定8個產品檔：`src/features/books/books.css`、`src/features/library/BookDetail.tsx`、`BookDetailCover.tsx`、`BookPublicationList.tsx`、`src/features/reading-cycles/ReadingCycleManager.tsx`、`BookReadingCycles.tsx`、`src/features/reading-records/ReadingRecordPopover.tsx`、`src/features/reading-contents/ReadingContentManager.tsx`。其餘為測試使用者操作步驟調整、2個測試helper／新案例檔及本文件；不改資料服務、schema、匯入、同步或部署設定。

## 驗證

- 相關元件7檔44個不同案例具備分批通過證據：封面草稿／版本保護、連續保存／返回位置、書目與閱讀事實分離、分次歸屬與日期精度、心得時間，以及新增的3入口／瀏覽不寫入資料、管理切換保留草稿驗證。修正後只補驗失敗案例或相關項，不重跑完整程式全套。
- 受影響Chromium／WebKit共19檔88個不同案例分批通過：核心34項（首輪28項通過，根據實際故障修正後補驗12項涵蓋原6個失敗與相關流程），其餘15檔54項（首輪50項，依新「未提供」呈現修正舊鉛筆提示斷言後補驗原4項通過）。不宣稱首輪全綠，未以重試掩蓋故障。
- 含320–1440px、大封面置中、預設3入口、閱讀／心得完整可見、無內容摺疊、200%文字放大、草稿保留、正常滑鼠點擊、編輯返回原位置，以及封面、資料持久化、同步與衝突、分類、書庫搜尋／篩選／返回流程。
- `npm run build`（含完整typecheck）與修改範圍TS／TSX ESLint通過、`git diff --check`通過；CSS由build解析與瀏覽器驗證，不宣稱ESLint有CSS規則。既有sql.js外部化與chunk大小提示保留。
- 實作合成截圖已目視核對：原工作區 `.local-dev/book-quiet-design/quiet-browsing-360.png`、`quiet-browsing-1440.png`。使用者提供的參考圖片未複製、上傳或提交GitHub。
- 本輪未執行完整程式全套、未觸發Actions；必要完整品質閘門留待準備發布時依規則補齊。

## 狀態與下一步

僅本機實作與定向驗證完成，尚未push／PR、私人承接、合併、預覽部署或正式部署。前批正式站仍為公開#8／私人#177的版本。本輪沒有讀寫正式書籍、紀錄、封面或Cloudflare設定；原工作目錄與既有工具修改保留。

本機合成驗收：先看手機與桌面標題／內文字體及預設3入口 → 開任一管理模式查看工具，完成後內容仍可直接閱讀 → 在閱讀或心得表單輸入草稿，確認必須保存／取消才能關閉相應管理模式。

下一個唯一優先：審閱這版實作的字體與管理入口，再準備私人承接及發布前必要驗證；不要求使用者在尚未更新的正式站驗收本輪，也不沿用前批發布／帳務例外授權。
