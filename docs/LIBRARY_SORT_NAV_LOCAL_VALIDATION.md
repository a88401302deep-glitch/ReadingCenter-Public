# 書庫排序與固定搜尋列：本機驗證

2026-10-29，基準公開maind685a73，本次唯一目標為書庫搜尋／排序／篩選操作整合。尚未私人承接、推送、PR或部署。

## 行為
- 搜尋及篩選按鈕整合進既有sticky導覽區，保持單一搜尋輸入；桌機同列，1100px以下搜尋放第二列。僅書庫顯示。
- 排序與原篩選放同面板：最近更新（原預設）、最近加入、最早加入、書名、作者、最近閱讀、最近完讀、評分高至低／低至高。排序作用於全部符合資料後才每30本分頁；改條件回第一頁；單書返回保留條件。
- 新增評分篩選：全部、已評分、已完讀待評分；原類型／閱讀狀態／完整度／分類／標籤／來源保留，清除條件也重設排序。
- 書名採繁中自然數字順序；評分跨五星／十分制按比例比較。缺作者／日期／評分置後，相同值穩定排序，不寫入資料。
- 最近閱讀／完讀只用既有明確日期，計畫日期不當成實讀；合格來源日保留原有有效閱讀門檻與完讀爭議排除。沒有閱讀日期時不以書籍建立／更新日補造。預設維持BookService最近更新的既有順序，包含相同時間的順序。
- 手機面板雙欄、限制高度，可內部捲動；展開時暫時隱藏浮動新增鈕避免遮欄位，收起恢復。粉色與六欄／單星評分不變。

## 驗證
- 最終5檔14項單元／元件通過（最初13項，補上作者／加入時間案例後單元檔3項通過）。涵蓋排序自然字序、跨制評分、缺值、實讀日期／排除計畫、分頁、Header及App閱讀評分。
- Chromium／WebKit共12個相關瀏覽器案例最終通過：6個既有書庫／評分案例、6個360／744／1280px固定導覽搜尋、排序與篩選、Escape焦點、返回原條件、清除重設與溢出檢查。手機面板高度修正後重跑新6項；其中744兩項測試誤認導覽一定在底部，改按實際fixed／頂部導覽邊界後重跑兩項通過，未放寬溢出或資料斷言。
- typecheck／範圍lint／build／diff check通過。未跑完整CI，未存取正式資料。
- 合成預覽.local-dev/library-sort-design/desktop.png、mobile.png已目視核對。

## 本機驗收
1. 在書庫捲動，搜尋欄仍在導覽區；點旁邊篩選。
2. 選書名／最近加入／評分排序，再套閱讀狀態或已完讀待評分。
3. 開書關閉後條件保留；清除條件回原預設。
