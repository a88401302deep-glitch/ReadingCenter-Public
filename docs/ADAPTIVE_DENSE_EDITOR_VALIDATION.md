# 緊湊預設／依內容增高：僅本機預覽

2026-10-30，從本機be94c19接續使用者回饋：封面操作重複用詞、表單仍過寬，普通資料應緊湊，少見的多作者合輯才增高。本輪維持「暫不發布」，不推送／更新PR／合併／部署。

唯一目標：減少重複操作文字、縮窄預設版面，讓長書名與多作者資料依真實內容增減高度並可保存。

- BookForm／BookCoverPaste：一個「封面」標籤搭配搜尋、上傳、貼上、移除四個短操作，尺寸只顯示數字。螢幕閱讀器標籤仍保留完整名稱；圖片與草稿保存流程保留。
- BookCreditField：書名與姓名單行起始，自動換行增高；刪短後縮回44px，不再以192px截斷長作者名單。書名保留required、焦點與原值，姓名可每行一位，畫面標題去掉重複的輸入提示。
- PublisherField：既有出版社選用改成文字框旁44px小下拉，完整選項及手動輸入保留；去除重複說明。Safari窄版原生select的溢出以容器裁切及外層focus-within焦點框處理。
- BookMetadataDialog：完整編輯的查詢工具由「補資料」在原頁展開／關閉；平常沒有第二個書名／查詢說明大區塊。已填書目欄位仍直接展開；原非inline查詢視窗及候選核對流程保留。
- site-theme：預設編輯寬度上限720px、出版短欄位、收緊標題帶與段距；手機滿寬封面保留。空封面僅80px提示，長作者不得把它一起拉成巨大空框。
- book-metadata-plan：手動作者名單上限由20增至100位，保留每位200字驗證；作者文字欄上限20099字容納100位姓名及換行。資料結構、同步與既有書籍不轉換；其他角色與來源擷取限制未擴充。

驗證：32項元件／單元通過，包含100位作者可保存、改成30位、101位／單名201字拒絕且不新增字典或改寫書籍。28個唯一分層Chromium／WebKit案例通過：自動增高4項、手機／平板8項、出版社4項、姓名4項、metadata8項。最終20項adaptive／tablet／metadata全過，最後空封面高度修正另做adaptive4項；typecheck／lint／build／diff check通過。涵蓋30位作者、長書名保存重開及縮回短內容，320／360／430手機與768／1024／1366平板無橫向溢出。

診斷：最初30位作者被原20位資料限制拒絕，已修正並加邊界測試；React memo引用依賴改為直接以DOM節點量測；新小型出版社選單的WebKit溢出已修正。編輯metadata測試改由「補資料」入口操作後候選核對／不覆寫人工欄位通過。沒有以重試替代診斷或降低檢查標準。

驗收：比較普通資料預覽與30位作者預覽；確認短操作及720px欄寬，再核對長資料增高而不預留空框。下一個唯一優先任務：依使用者對密度與按需增高的回饋調整，維持暫不發布。
